Política de privacidade

O Arthur OpenClaw é um assistente de uso estritamente pessoal, usado apenas pelo próprio dono, com a conta Google dele.

  • Acessa a Agenda, o Planilhas e o Drive do Google somente para cumprir pedidos do dono.
  • Os dados não são vendidos, compartilhados, publicados nem usados para publicidade.
  • Os tokens de acesso ficam guardados apenas no computador do dono.
  • O acesso pode ser revogado a qualquer momento em myaccount.google.com, em Segurança, Apps de terceiros.

O uso dos dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Privacy policy

Arthur OpenClaw is a strictly personal assistant, used only by its owner with the owner's own Google account.

  • It accesses Google Calendar, Sheets and Drive only to carry out the owner's requests.
  • Data is never sold, shared, published or used for advertising.
  • Access tokens are stored only on the owner's computer.
  • Access can be revoked at any time at myaccount.google.com, under Security, Third-party apps.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
